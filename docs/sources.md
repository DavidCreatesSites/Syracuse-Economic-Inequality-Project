# Sources

The maintained citation directory is in [Sources](../sources.html), grouped by publisher. Numbered links throughout the website open MLA-style citations drawn from `../assets/js/source-catalog.js`.

The [research review](research-review.md) records manuscript coverage, source checks, corrected definitions, and unresolved evidence. Do not assume that a linked citation means every manuscript value has been independently verified; consult each chart’s review label.
